# BMMB554: Biological Data Analysis

Course website for BMMB554 at Penn State University.

## About

This course introduces computational approaches for analyzing biological data. Topics include:

- Python programming fundamentals
- Unix/Bash command line
- Data manipulation and visualization
- Biological data analysis workflows

## Local Development

This site is built with [Quarto](https://quarto.org/).

### Prerequisites

- [Quarto](https://quarto.org/docs/get-started/)
- Python with Jupyter (for notebook rendering)

### Preview Locally

```bash
quarto preview
```

### Build Site

```bash
quarto render
```

## Lectures

1. **Python 1**: Variables, expressions, statements, functions
2. **Introduction to Bash**: Command line basics, navigation, pipes, loops
